# Visão Geral — moodle-atto_justify

O **`moodle-atto_justify`** é um plugin de editor de texto para o Moodle que estende a barra de ferramentas do editor **Atto**, adicionando o botão e a funcionalidade nativa de **alinhamento de texto justificado** (`text-align: justify`).

---

## 🚀 Principais Recursos

- **Alinhamento Justificado NATIVO**: Permite formatar parágrafos com alinhamento justificado diretamente no editor Atto.
- **Integração com a Barra Atto**: Adiciona-se perfeitamente aos grupos de botões de alinhamento existentes.
- **Suporte YUI / Shifter**: Código-fonte JavaScript estruturado na arquitetura YUI do Moodle, pré-compilado com `shifter`.
- **Compatibilidade Moodle**: Projetado para Moodle 3.x e 4.x com suporte ao editor Atto.
