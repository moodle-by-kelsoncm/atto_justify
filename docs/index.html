moodle-atto_justify

Plugin para o editor Atto do Moodle que adiciona a funcionalidade e botão de alinhamento de texto justificado.

Visão Geral

O plugin moodle-atto_justify estende a barra de ferramentas do editor Atto nativo no Moodle, adicionando o botão de justificar texto em parágrafos e seleções de conteúdo.

  • Suporte nativo ao editor Atto (Moodle 3.x / 4.x)
  • Código JavaScript pré-compilado via framework YUI (Shifter)
  • Aplicação direta de regras text-align: justify

Instalação

Instale o plugin dentro do diretório de plugins do editor Atto:

cd /caminho/do/moodle/lib/editor/atto/plugins
git clone https://github.com/moodle-by-kelsoncm/moodle-atto_justify.git justify

Após clonar, acesse Administração do site → Notificações para concluir a instalação.

Configuração

  1. Acesse: Administração do site → Plug-ins → Editores de texto → Configurações da barra de ferramentas Atto.
  2. Na caixa Configuração da barra de ferramentas, localize a linha align = align.
  3. Altere para: align = align, justify.
  4. Salve as alterações.

Desenvolvimento (Shifter)

Para modificar o arquivo de botões do YUI em yui/src/button/js/button.js, compile usando o shifter:

cd yui/src/button
sudo shifter
