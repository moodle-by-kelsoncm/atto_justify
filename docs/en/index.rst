moodle-atto_justify
===================

**moodle-atto_justify** is a text editor plugin for Moodle that extends the **Atto** editor toolbar, adding the native button and functionality for **justified text alignment** (``text-align: justify``).

Key Features
------------

* **Native Justify Alignment**: Allows formatting paragraphs with justified alignment directly in the Atto editor.
* **Seamless Atto Integration**: Integrates cleanly into existing text alignment button groups.
* **YUI / Shifter Support**: JavaScript source structured under Moodle's YUI architecture, pre-compiled with ``shifter``.
* **Moodle Compatibility**: Designed for Moodle 3.x and 4.x supporting the Atto editor.
